# 🏥 Insurance Charges Prediction using Linear Regression

## 📌 Overview
This project predicts medical insurance charges based on patient data using a Linear Regression model. It covers a complete ML pipeline — from data cleaning to model evaluation.

## 📂 Dataset
- Source: [Kaggle - Medical Cost Personal Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance)
- Features: age, sex, bmi, children, smoker, region, charges, and more

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn, Statsmodels

## 🔄 Project Pipeline
1. Data Loading & Exploration
2. Handling Missing Values & Duplicates
3. Outlier Detection & Removal (IQR Method)
4. Label Encoding for Categorical Variables
5. Correlation Analysis (Heatmap)
6. Multicollinearity Check using VIF
7. Train-Test Split (80/20)
8. Linear Regression Model Training
9. Evaluation — R², MAE, RMSE
10. Actual vs Predicted Visualization

## 📊 Results
| Metric | Value |
|--------|-------|
| R² Score | 0.8671 |
| MAE | 2600.41 |
| RMSE | 4248.75 |
